# Little Joys Flavour Finder

> **Independent student concept** for the Mosaic Wellness Fellowship Builder Challenge.  
> Not an official Little Joys product. Does not provide nutrition or medical advice.

A personal tasting journal that helps a household remember which Little Joys NutriMix flavours worked well, so choosing the next pack feels less like guesswork.

## Run (development)

```powershell
npm run dev
```

Starts **both** services concurrently and keeps them alive:

| Service  | Default URL                   | Port  |
|----------|-------------------------------|-------|
| Frontend | http://localhost:5174          | 5174  |
| Backend  | http://localhost:3101          | 3101  |

Vite proxies all `/api/*` requests to the backend, so the React app talks to the API without CORS issues or hardcoded URLs.

> **If port 5174 is taken**, Vite will auto-increment to 5175, 5176, etc. (strictPort is off).  
> **If port 3101 is taken**, set `API_PORT=3200` (or any free port) in a `.env` file or as an environment variable before running.

Run each service independently if needed:

```powershell
npm run dev:frontend   # Vite only
npm run dev:backend    # Express only
```

## API endpoints

Base URL in development: `http://localhost:3101`

| Method   | Path              | Description                                   |
|----------|-------------------|-----------------------------------------------|
| `GET`    | `/api/health`     | Returns `{ ok: true, app: "..." }`            |
| `GET`    | `/api/tastings`   | Returns array of saved tasting entries        |
| `POST`   | `/api/tastings`   | Saves a tasting (see fields below)            |
| `DELETE` | `/api/tastings`   | Clears all saved entries (confirmed in UI)    |

### POST body fields

```json
{
  "flavour":     "Chocolate | Strawberry | Vanilla",
  "rating":      1–5,
  "texture":     "smooth | okay | not-for-us",
  "wouldChoose": "yes | maybe | no",
  "note":        "optional string, max 180 chars"
}
```

Invalid input returns `400 { "error": "..." }`.

## Data storage

Tastings are saved to `backend/data/tastings.json` on this machine.  
This folder is in `.gitignore` — it is never committed.

**To delete all data manually:**

```powershell
Remove-Item backend\data\tastings.json
```

Or use the **Clear notes** button in the app (requires confirmation).

## Build (production)

```powershell
npm run build
```

Outputs to `dist/`. The backend (`npm start`) does not currently serve `dist/` — for a demo deploy, either:

- **Serve `dist/` as a static site** (Netlify, Vercel, GitHub Pages) with the backend deployed separately and `VITE_API_BASE` set, or
- **Add Express static serving** of `dist/` before the SPA fallback if you want a single-process deploy.
